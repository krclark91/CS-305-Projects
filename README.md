# CS-305-Project-Two


Artemis Financial, a financial consulting company specializing in individual savings, retirement, investments, and insurance plans, sought to modernize its RESTful API while incorporating robust software security. Through a combination of manual code reviews and automated tools like OWASP Dependency-Check, critical vulnerabilities-such as hardcoded credentials, unauthenticated endpoints, and outdated libraries-were identified and documented in a comprehensive vulnerability assessment report. To mitigate these risks and secure sensitive customer data, the application was hardened using cryptographic controls like AES-256-GCM and SHA-256, HTTPS/TLS configuration via Java Keytool, and code-level refactoring. These enhancements were verified through endpoint testing and checksum validations, underscoring the vital role of proactive secure coding, ongoing dependency auditing, and regression testing in protecting business continuity and customer trust.
